Política de privacidad

Córdoba en Efemérides (app para Android y versión web). Última actualización: 21 de noviembre de 2026.

Resumen

La app no recoge, no guarda en servidores y no comparte ningún dato personal. No tiene cuentas de usuario, publicidad ni herramientas de análisis.

Qué se guarda y dónde

Tus favoritas, la hora del aviso, el tamaño de letra y el récord del juego se guardan solo en tu dispositivo. Nunca salen de él y se borran al desinstalar la app (o al borrar los datos del navegador, en la versión web).

Conexión a internet

Para estar al día, la app descarga el archivo público de efemérides desde GitHub (raw.githubusercontent.com), y la versión web se aloja en GitHub Pages. En esas descargas no se envía ningún dato tuyo. Como cualquier servidor web, GitHub puede registrar datos técnicos de la conexión (como la dirección IP); consulta la declaración de privacidad de GitHub.

Permisos

Notificaciones: solo para el aviso diario con la efeméride del día. Se programa en el propio dispositivo y puedes desactivarlo en cualquier momento.
Internet: solo para descargar las efemérides actualizadas.

Compartir

Cuando pulsas «Compartir», la app prepara una imagen y un texto y abre el menú de tu dispositivo. Lo que compartas y con quién lo decides tú, en la app que elijas.

Menores

La app no está dirigida específicamente a menores y no recoge datos de nadie.

Contacto

Para cualquier duda sobre esta política, puedes escribir a través del proyecto en GitHub o al correo de contacto que aparece en la ficha de Google Play.
